Usuarios del sistema

Al agregar a alguien, el sistema genera una contraseña temporal que deberá cambiar al entrar. Cuando se active el inicio con Microsoft 365, las personas nuevas se registrarán solas como "Usuario" y aquí solo ajustarás su rol y su área. Para cargar a muchos de una vez, usa python gestionar.py importar-usuarios en el servidor.
Roles: Usuario crea y sigue sus tickets · Analista de soporte atiende tickets · Administrador tiene control total (puede haber varios; siempre debe quedar al menos uno).

📥 Importar lista de trabajadores

  1. Descarga la plantilla de Excel o usa tu propia lista: necesita las columnas Nombre, Correo, Área y Rol (Usuario, Analista o Administrador; si lo dejas vacío, será Usuario).
  2. Elige el archivo (.xlsx, .xls o .csv). Primero verás una revisión; todavía no se crea nada.
  3. Pulsa Importar y descarga las contraseñas temporales para entregarlas.
